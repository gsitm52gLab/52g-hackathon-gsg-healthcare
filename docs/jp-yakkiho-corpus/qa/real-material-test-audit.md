### 파생 테스트 레코드에 허용할 필드

- `case_id`, `source_file_alias`, `page_or_slide`
- 광고 문구의 짧은 최소 발췌
- 공개 가능한 제품 분류(`general_cosmetic`, `quasi_drug`, `unknown`)
- 필요한 경우 성분의 공개 표시명과 배합 목적
- 사람이 작성한 기대 rule_id와 `needs_human_review`

### 반드시 제거할 필드

- 발신·수신·참조자 이름, 이메일, 전화, 주소, 서명
- 회사 내부 마감일, 견적, 판매계획, 협상·검수 의견의 작성자 식별정보
- 인보이스, 은행/결제, 계약 번호
- 전체 성분표나 제조 조성 중 공개 여부를 확인하지 않은 정보
- 문서 URL, 내부 시스템 경로, 메일 메시지 ID

## 테스트 입력 전 확인해야 할 제품 분류 context

현재 두 핵심 PDF만으로는 개별 제품의 일본 내 법적 분류가 확정되지 않는다. 프롬프트 입력에는 적어도 다음을 포함해야 한다.

1. `product_class`: 일반화장품 / 의약부외품 / 기타 / 미확인
2. `product_name`과 판매명·별칭, 일본 판매 대상 SKU
3. 의약부외품이면 승인된 효능·유효성분·승인 표현
4. 일반화장품이면 제품 유형과 JCIA 효능 범위에 대응하는 의도된 효능
5. 매체와 위치: 브랜드 페이지, 보도자료 제목/본문, 패키지 전면/후면, SNS 등
6. 문구 주변의 전체 문장, 이미지, 강조 크기, 별표와 주석의 실제 배치
7. 원산지·독자기술·조사수치·수상/순위 등 객관 주장에 대한 근거 존재 여부

분류가 없으면 모델은 `context_missing` 또는 `conditional`로 반환해야 하며, 일반화장품이라고 임의 추정해 최종 적합/부적합 판정을 내려서는 안 된다.

## 추출·시각검수 메모

- PPTX 6슬라이드는 모두 그림으로 구성되어 XML 텍스트가 없다. 시각 확인 결과 영문/한국어 패키지 초안이며 일본어 문구는 확인되지 않았다. `BRIGHTEOUS MOISTURIZER`, `TO GO ESSENCE SUN SCREEN SPF50+ PA++++`, `BRIGHTEOUS SERUM`, `WHITE DANDELION ESSENCE SOO`, `FACE CREAM`, `FACE CLEANSER` 등은 제품 context로만 활용 가능하다.
- `MashBeautyLab 거래처 대상 협업 메뉴(한글).pdf` 35쪽은 완전 이미지 PDF다. 한국어 B2B/기밀 자료이므로 이번 목적에서는 OCR 비용을 들일 필요가 없다.
- `MSDS_Talitha Koum Face Cleanser.pdf` p.2~5는 텍스트가 비어 있으나 비대상 MSDS이므로 OCR 우선순위가 없다.
- 이메일 PDF에 포함된 이미지나 캡처는 텍스트 추출만으로 글자 크기·주석 연결·강조를 재현할 수 없다. 핵심 후보 RM-03~RM-05를 실제 평가셋으로 확정할 때 p.3 원페이지 이미지를 내부 환경에서 사람 검수해야 한다.
- `JFUN` 파일에는 한국어로 `립큐어밤 부문 제1위` 근거/주석 관련 실제 검수 기록이 있으나 일본어 원문 광고가 분리되어 있지 않다. 일본어 리플렛 원본을 별도로 확보하기 전에는 일본어 입력 테스트셋에 넣지 않는 것이 안전하다.
