# 04. 실제 자료 테스트 케이스

- [실제 업무자료 읽기 전용 감사](../jp-yakkiho-corpus/qa/real-material-test-audit.md)

현재 감사에서 바로 전사 가능한 일본어 광고 후보는 핵심 PDF 2개에서 선별한 **RM-01~RM-08 8건**이며, 비제품 광고 오탐 확인용 **NC-01~NC-02 2건**도 있다. 빠른 데모 권장 세트는 RM-01, RM-03, RM-05, RM-06, RM-07, RM-08이다.

아직 익명화된 JSONL 케이스 파일은 만들지 않았다. 감사 문서의 기준에 따라 광고 문구의 최소 발췌만 수기 전사하고 다음을 제거한 뒤 추가해야 한다.

- 이름, 이메일, 전화, 주소, 서명과 메일 헤더
- 내부 일정·견적·협상 내용, 인보이스·계약 정보
- 공개 여부가 확인되지 않은 전체 성분표·제조 조성
- 문서 URL, 내부 경로, 메시지 ID

Downloads의 원본 문서는 이 패키지에 복사하지 않았고 외부 모델에 업로드하면 안 된다. 원본 전체가 아닌 익명화된 최소 문구와 필요한 제품 context만 사용한다.
