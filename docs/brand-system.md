# GS HALE 브랜드 시스템

상태: `baseline`  
적용 대상: 제품 UI, 데모, 발표자료, 문서, 에이전트가 생성하는 사용자 문구

## 1. 브랜드 정의

### 공식 제품명

**GS HALE**

### 영문 확장

**H**ealthcare & **A**esthetic **L**aunch **E**nablement

### 한국어 메시지

- 대표 설명: **해외 헬스케어 진출의 모든 일**
- 이름 기억 장치: **해**외 헬스케어 진출 업무를 **일**원화하다.
- 캠페인 메시지: **글로벌 헬스케어의 새로운 물결**

### 한 문장 제품 설명

GS HALE은 해외 헬스케어·에스테틱 시장 진출에 필요한 요청, 자료, 수정, 검수와 최종 사용본을 하나의 흐름으로 연결하는 운영 플랫폼입니다.

## 2. 이름 사용법

| 상황 | 표기 |
| --- | --- |
| 로고·제품 헤더 | `GS HALE` |
| 한국어 첫 언급 | `GS HALE(지에스 헤일)` |
| 이후 본문 | `GS HALE` 또는 문맥이 명확할 때 `HALE` |
| 영문 설명 병기 | `Healthcare & Aesthetic Launch Enablement` |
| 내부 기억 장치 | `GS 해일` |

### 해야 할 것

- 영문 워드마크는 `GS HALE`처럼 모두 대문자로 씁니다.
- 한국어 문장에서는 공식 발음을 `헤일`로 안내합니다.
- `해일`은 “해외 헬스케어의 모든 일”과 “새로운 물결”을 설명하는 보조 장치로 씁니다.

### 하지 말아야 할 것

- `GS Hale`, `GSHALE`, `G.S. HALE`처럼 임의로 바꾸지 않습니다.
- `해일`의 재난·파괴 이미지를 직접 활용한 그래픽이나 카피를 만들지 않습니다.
- 파도 그래픽을 과도하게 사용해 해양·물류 서비스로 오인하게 하지 않습니다.
- `AI 승인`, `규제 통과`, `법률 검토 완료`처럼 제품이 보장하지 않는 표현을 쓰지 않습니다.

## 3. 메시지 구조

메시지는 다음 순서로 작성합니다.

1. 사용자의 다음 행동
2. 대상 제품·업무·파일 버전
3. 기한과 책임자
4. 현재 상태와 근거
5. 필요한 경우에만 브랜드 메시지

### 권장 카피

- `수정본 v3을 9월 22일 12:00 KST까지 제출해 주세요.`
- `외부 기관 답변을 기다리고 있습니다. 다음 확인: 9월 24일 · 담당: 이지선`
- `AI 사전검토 결과입니다. 최종 판단에는 사람 전문가의 확인이 필요합니다.`
- `이 검수 결과는 일본어 패키지 v3에만 적용됩니다.`

### 피할 카피

- `곧 마감됩니다.` — 정확한 시각과 시간대가 없음
- `검수 통과` — 검수 주체·버전·사용 범위가 없음
- `AI가 승인했습니다.` — AI 권한을 과장함
- `문제없음` — 미탐지와 적합 판정을 혼동함

## 4. GS CI 적용

GS 공식 CI는 Orange, Green, Blue를 기본으로 하며, 서비스 영역의 대표 Accent Color로 Jade Green을 사용합니다. 아래 값은 프로토타입용 디지털 기준입니다.

| 역할 | 토큰 | 기준값 | 사용 |
| --- | --- | --- | --- |
| GS Jade Green | `brand.gs.jade` | `#00A99D` | 브랜드 강조, 로딩, 그래픽 모티프 |
| GS Blue | `brand.gs.blue` | `#3366CC` | 링크, 정보, GS 리더십 이미지 |
| GS Green | `brand.gs.green` | `#99CC00` | 보조 그래픽, 성장 모티프 |
| GS Orange | `brand.gs.orange` | `#CC6600` | 제한적인 에너지 강조 |
| GS Cool Gray | `brand.gs.gray` | `#787878` | CI 보조색 |
| GS Warm Gray | `brand.gs.warm-gray` | `#EBEBE3` | 따뜻한 중립 배경 |

중요:

- CI 색상값은 로고를 다시 그리기 위한 값이 아닙니다.
- 공식 GS/GS Global 로고를 변형·재조합·재채색하지 않습니다.
- 승인된 로고 자산이 없을 때는 프로토타입에서 텍스트 `GS HALE`만 사용합니다.
- GS Jade `#00A99D`, GS Green, GS Orange 위에 흰색 본문을 올리지 않습니다. 일반 텍스트 대비가 충분하지 않을 수 있습니다.
- 제품의 상태 의미에는 원색 CI를 직접 연결하지 않고, [디자인 시스템의 시맨틱 토큰](design-system.md#5-색상)을 사용합니다.

## 5. 시각 모티프

### Flow line

GS HALE의 주 모티프는 파도 그림이 아니라 **연결된 업무의 흐름**입니다.

- 하나의 선이 요청 → 제출 → 검수 → 수정 → 최종 전달을 연결합니다.
- 선의 분기에는 책임자, 버전, 근거가 붙습니다.
- 닫힌 원은 완료가 아니라 연결된 기록을 의미합니다.
- 움직임은 진행 방향을 설명할 때만 사용하며 장식용 반복 애니메이션은 금지합니다.

### 이미지

- 제품, 패키지, 사람이 실제로 검토·협업하는 맥락을 우선합니다.
- 청진기, 십자가, 알약 같은 의료 클리셰만으로 헬스케어를 표현하지 않습니다.
- 화장품 이미지만 반복해 진단·덴탈 등 확장 영역을 배제하지 않습니다.
- AI를 사람 얼굴형 로봇이나 마법 효과로 표현하지 않습니다.
