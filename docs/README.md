# GS HALE 문서

이 디렉터리는 사람과 AI 에이전트가 같은 제품 판단을 내리기 위한 기준선입니다.

## 읽는 순서

1. [브랜드 시스템](brand-system.md): 제품명, 메시지, CI와 색상 사용법
2. [디자인 시스템](design-system.md): 토큰, 레이아웃, 컴포넌트, 상태와 접근성
3. [`../jp-yakkiho-corpus/README.md`](../jp-yakkiho-corpus/README.md): 일본 약기법 사전검토 코퍼스 계약

## 문서의 역할

| 문서 | 결정하는 것 | 결정하지 않는 것 |
| --- | --- | --- |
| `brand-system.md` | 이름, 보이스, 로고·색상 원칙 | 개별 화면 배치 |
| `design-system.md` | UI 토큰, 패턴, 상태, 에이전트 판단 규칙 | 법률 판단과 업무 정책 |
| 코퍼스 README | 근거·버전·사전검토 안전 계약 | 제품의 시각 스타일 |

## 변경 규칙

- 새 색상, 간격, 상태 또는 컴포넌트를 추가하기 전에 기존 토큰과 패턴으로 해결 가능한지 확인합니다.
- 새로운 전역 규칙은 이 문서에 먼저 기록한 뒤 화면에 적용합니다.
- 임시 시안의 값은 디자인 시스템 기준으로 승격되기 전까지 전역 토큰이 아닙니다.
- 접근성이나 도메인 안전을 약화하는 변경은 시각적 선호를 이유로 허용하지 않습니다.
- GS CI 원본과 사용 규정은 저장소 문서보다 최신 공식 가이드가 우선합니다.
