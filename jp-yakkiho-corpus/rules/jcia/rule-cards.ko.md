## JCIA-R-001 · 광고 해당성과 전체 인상

- 위험 유형: `scope_and_overall_impression`
- 제품: cosmetic, quasi_drug, medicated_cosmetic, unknown
- 채널: all
- 탐지 개념: 제품명과 구매 유도, 효능 정보, 브랜드 제공 콘텐츠, 연결된 여러 화면

검토 질문

- 고객 유인 의도, 특정 제품 식별, 일반인의 인지 가능성이 함께 있는가?
- 문구 하나가 아니라 이미지·음성·주석·연결 페이지를 합친 전체 인상이 무엇인가?

허용 가능한 맥락

- 광고 해당성과 표현 평가는 형식이나 단어 하나가 아니라 전체 맥락을 기록해 사람이 판단한다.

문제 가능성이 있는 맥락

- 제품명이 첫 화면에 없다는 이유만으로 연결 페이지의 광고성을 배제한다.
- 작은 주석으로 주된 과장 인상이 해소된다고 가정한다.

필요 증거

- 최종 광고 전체본
- 연결 URL과 화면 흐름
- 게시 주체와 목적

상향 조건

세 요건 또는 전체 인상이 불명확하면 광고 해당성을 확정하지 말고 규제 담당자에게 상향한다.

## JCIA-R-002 · 제품 분류 선확인

- 위험 유형: `product_classification`
- 제품: cosmetic, quasi_drug, medicated_cosmetic, unknown
- 채널: all
- 탐지 개념: 일반화장품, 의약부외품, 약용화장품, 승인 효능

검토 질문

- 일본에서의 제품 분류가 무엇인가?
- 의약부외품이면 개별 승인 효능·효과 자료가 있는가?

허용 가능한 맥락

- 제품 분류와 승인 범위를 먼저 고정한 뒤 해당 범위 안에서 문안을 검토한다.

문제 가능성이 있는 맥락

- 한국 분류를 일본 분류로 그대로 사용한다.
- 약용이라는 명칭만으로 승인 효능을 추정한다.

필요 증거

- 일본 제품 분류 자료
- 승인서 또는 신고 정보
- 판매명

상향 조건

분류 또는 승인 범위가 누락되면 모든 효능 검토를 근거 확인 필요로 유지한다.

## JCIA-R-003 · 판매명·약칭·애칭의 오인 방지

- 위험 유형: `misleading_product_name`
- 제품: cosmetic, quasi_drug, medicated_cosmetic
- 채널: all, package
- 탐지 개념: 약칭, 애칭, 성분명 제품명, 의약품처럼 보이는 명칭

검토 질문

- 정식 판매명이 명확한가?
- 약칭이나 애칭이 효능·성분·의약품 지위를 오인시키는가?

허용 가능한 맥락

- 정식 판매명과의 관계가 분명하고 제품 식별용으로만 쓰이는 약칭 또는 애칭.

문제 가능성이 있는 맥락

- 승인되지 않은 효능을 암시하는 명칭.
- 특정 성분이나 약을 연상시키며 제품 본질을 오인시키는 명칭.

필요 증거

- 일본 판매명
- 라벨 시안
- 명칭 사용 맥락

상향 조건

판매명 등록 상태나 제품 분류와 충돌하면 표시 담당자에게 상향한다.

## JCIA-R-004 · 제조·연구 우수성 과장

- 위험 유형: `manufacturing_or_research_superiority`
- 제품: cosmetic, quasi_drug, medicated_cosmetic
- 채널: all
- 탐지 개념: 최고 기술, 최첨단 제조, 독자 연구, 완벽한 품질

검토 질문

- 제조·연구 설명이 사실이며 검증 가능한가?
- 최대급·보증·타사 우월 인상을 만드는가?

허용 가능한 맥락

- 확인 가능한 공정 또는 연구 사실을 제한적으로 설명한다.

문제 가능성이 있는 맥락

- 근거 없이 기술·시설·연구의 최고성이나 결과의 확실성을 강조한다.

필요 증거

- 제조 공정 자료
- 연구 기록
- 비교 주장 근거

상향 조건

## JCIA-R-005 · 의약부외품 효능은 개별 승인 범위 내

- 위험 유형: `unapproved_quasi_drug_claim`
- 제품: quasi_drug, medicated_cosmetic
- 채널: all
- 탐지 개념: 약용 효능, 미백, 여드름 방지, 살균, 육모, 주름개선

검토 질문

- 표현이 해당 제품의 실제 승인 효능·효과 안에 있는가?
- 효능에 붙은 조건 문구도 같은 수준으로 인지되는가?

허용 가능한 맥락

- 개별 승인된 효능·효과와 필요한 제한 조건을 소비자가 함께 이해할 수 있게 제시한다.

문제 가능성이 있는 맥락

- 제품군 일반 효능표만 보고 개별 제품의 미승인 효능을 주장한다.
- 조건 문구를 약하게 표시해 효능 범위를 넓혀 보이게 한다.

필요 증거

- 개별 승인서
- 승인 효능·효과 원문
- 최종 레이아웃

상향 조건

승인서가 없거나 번역 문구와 승인 문구의 등가성이 불명확하면 일본 규제 담당자에게 상향한다.

## JCIA-R-006 · 일반화장품 효능 범위

- 위험 유형: `cosmetic_claim_out_of_scope`
- 제품: cosmetic
- 채널: all
- 탐지 개념: 치료, 예방, 재생, 기능 개선, 신체 구조 변화

검토 질문

- 문안이 후생노동성의 화장품 효능 범위 또는 물리적 메이크업 효과 안인가?
- 약리작용이나 질병 치료·예방을 암시하는가?

허용 가능한 맥락

- 허용된 화장품 효능 범위와 사실인 사용감·물리적 효과를 구분하여 표현한다.

문제 가능성이 있는 맥락

- 일반화장품이 신체 기능을 바꾸거나 질환을 개선한다고 암시한다.
- 효능 범위 밖 문구를 주석으로 구제하려 한다.

필요 증거

- 문구별 대응 효능 번호
- 제품 사용 방식
- 물리적 효과 근거

상향 조건

## JCIA-R-007 · 메이크업·물리적 효과의 한시성

- 효과 지속 조건

## JCIA-R-032 · 인터넷 광고주와 책임 주체 표시

- 위험 유형: `missing_advertiser_identity`
- 제품: cosmetic, quasi_drug, medicated_cosmetic
- 채널: web, social, marketplace, landing_page
- 탐지 개념: 광고주 미표시, 브랜드 계정, 판매자 페이지, 제휴 콘텐츠

검토 질문

- 소비자가 광고 책임 주체를 명확히 알 수 있는가?
- 광고주·판매자·플랫폼의 역할이 혼동되지 않는가?

필요 증거

- 계정 소유 정보
- 게시 화면

상향 조건

광고주 또는 게시 책임이 불명확하면 채널 운영·법무 담당자에게 상향한다.
