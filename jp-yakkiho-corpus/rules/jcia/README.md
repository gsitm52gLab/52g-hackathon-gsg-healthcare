# JCIA 실무 규칙 카드

이 디렉터리는 JCIA(일본화장품공업회)의 공개 광고 가이드를 사람이 다시 읽고 작성한 한국어 검토 규칙이다. JCIA 원문 전문, 전체 TXT 또는 전체 번역본은 포함하지 않는다. 각 카드는 원문 위치로 돌아갈 수 있는 locator를 제공하지만, 법령 위반을 확정하는 판정표가 아니다.

## 판본 사용 순서

1. `JP-JCIA-AD-2026-ALPHA`: 2026-07-24 개정 알파판. 현재 실무 검토의 우선 참조이지만 정식 확정판은 아니다.
2. `JP-JCIA-AD-2020-2ND`: 2020년판 제2쇄. 이전 정식판이며 알파판의 변경 의미를 확인할 때 사용한다.
3. `JP-JCIA-INET-2017`: 인터넷 광고에 추가되는 채널별 자율기준이다.
4. 법적 판단은 `legal_basis`로 연결된 e-Gov·후생노동성 자료를 우선한다.

2017년 인터넷 광고 기준의 공식 Q&A집도 `ruleset.yaml`의 보조 출처 인벤토리에 등록했다. 인터넷 실무 카드 `JCIA-R-031`~`JCIA-R-033`은 기준 본문과 함께 관련 Q&A의 정확한 문항·PDF 페이지를 `supporting_guidance`로 연결한다. Q&A 연결은 업계 보조지침이며 법적 근거를 대체하지 않는다.

`rule-cards.ko.md`가 팀원이 읽는 핵심 문서이고 `rules.jsonl`은 그 기계 판독용 원본이다. `rules.schema.json`은 카드 필드 계약, `ruleset.yaml`은 출처·판본·출력 정책, `version-diff.yaml`은 2020판과 2026 알파판의 변경 요약이다. `finding.schema.json`은 향후 서비스 실험용 선택적 프로토타입이다.

## AI 사용 계약

AI는 문안에서 검토 후보를 찾고 질문과 필요한 증거를 제시할 수 있다. `위법`, `적법`, `승인`, `반려`를 확정해서는 안 된다. 각 결과의 고정 결론은 `관련 조항과 충돌 가능성이 있는 문제 후보`이다. AI 상태는 `검토 후보` 또는 `근거 확인 필요`만 사용하고, `담당자 검토 완료`는 별도의 사람 검토 상태에서만 설정한다. 제품 분류, 일본 승인 내용, 전체 광고 인상 또는 근거가 불명확하면 담당자에게 상향한다.

UI에서는 근거를 권위 순서와 정확한 locator로 표시한다. 예:

```text
약기법 제66조 제1항 → 의약품 등 적정광고기준 第4-3(5) → JCIA F7/p.24-26
```

법률·통지의 정확한 anchor를 찾지 못한 경우에는 `exact_basis_unresolved: true`를 그대로 표시하고, 근거를 추정해 만들지 않는다.

약기법 제67조는 특정 질병용 의약품·재생의료제품을 대상으로 하므로 현재 일반화장품·의약부외품 문안 카드에는 직접 연결하지 않는다. 제68조는 화장품 문안이 미승인 의약품 등의 영역으로 넘어가는 경계를 찾는 `JCIA-R-035`에 연결한다. 재분류 가능성이 있으면 이 ruleset의 자동 검토를 중단하고 전문가에게 상향한다.

## 검증

```bash
scripts/validate
.venv/bin/python -m unittest rules/jcia/test_validate_rules.py
scripts/build_search_index
```

검증기는 실제 JSON Schema, additional properties, ID·risk type 중복, manifest anchor 소유권, URL·판본, JCIA locator 허용목록, 커버리지, UTF-8·NFC·LF, 출력 정책 고정값과 원문 장문 혼입 방지용 길이 제한을 검사한다.

## 업데이트

JCIA 목록 페이지에서 정식 개정판이 발표되면 알파판을 자동 승격하지 않는다. 새 문서 ID와 새 카드를 만든 뒤 사람 검토를 거쳐 `version_status`와 `ruleset.yaml`을 갱신한다. 기존 카드는 감사 추적을 위해 보존한다.
